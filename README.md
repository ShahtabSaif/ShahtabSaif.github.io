# Shahtab Hossain — Portfolio

Source code for my personal portfolio site, built as a single static HTML page.

**Live site:** [shahtabsaif.github.io](https://shahtabsaif.github.io)

## About

I'm a developer and designer working across embedded systems, Android development, and visual design. This site covers my background, skills, and a few selected projects.

## Tech

- Plain HTML, CSS, and a bit of SVG animation — no build step, no dependencies
- Fonts: Space Grotesk, JetBrains Mono, Inter (via Google Fonts)
- Hosted on GitHub Pages

## Structure

```
index.html   → the entire site (markup, styles, and hero animation)
```

## Running locally

Just open `index.html` in a browser — no server or build tools needed.
